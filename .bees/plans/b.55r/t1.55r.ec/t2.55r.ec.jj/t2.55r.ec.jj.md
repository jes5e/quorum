## Context

Documentation Task of Epic 1 (t1.55r.ec, context-window guard). Task 1 defines the gauge-file contract (path, fields, overwrite/freshness semantics); this Task publishes that contract in the customer-facing docs so that an operator of ANY environment — including one where a higher-precedence settings source pins the status-line slot and `/quo-setup` cannot install the producer — can satisfy the contract with their own producer. The contract is *defined* by this Epic, so its documentation folds in here rather than into a separate doc Epic.

Authoritative spec: Spec Bee b.8sh → SDD child (t1.8sh.cg) `## Documentation` (customer-facing docs bullet) and PRD child (t1.8sh.c4) FR6 (published contract) plus the restricted-environment acceptance criterion.

## What Needs to Change

Add a gauge-file-contract section to the customer-facing docs (resolved from the target repo's CLAUDE.md `## Documentation Locations` → `Customer-facing docs` key) covering:

- **Location**: `<tempdir>/.quorum/context-usage-<session_id>.json`, with the per-OS tempdir resolution stated in the same style the docs already use for the `.quorum` scratch namespace.
- **Required fields**: top-level `session_id` and the `context_window` object with `used_percentage` (the field the consumer thresholds on), noting the write is the whole `context_window` object as received.
- **Overwrite-per-session semantics**: one file per session id, truncate-and-overwrite on every status-line refresh (a live gauge, not a log), never deleted by the workflow; freshness is judged from the file's modification time.
- **Restricted / pinned-statusline-environments note**: telling an environment owner whose configuration pins the status-line slot how to satisfy the contract with their own producer — any process that writes a conforming file at the published path keeps the guard working, with no quorum-side change needed.
- **Reconcile the adjacent README inventories**: the existing scratch-files subsection's inventory and delete-safety guidance (the gauge is a new resident of `<tempdir>/.quorum/`, recreated by the status-line refresh rather than by any skill) and the bundled-helper example list (name `context_gauge.py` with a short parenthetical) — cross-linking to the new contract section rather than restating it.

## Why

The producer/consumer split makes the published file contract the single point of interoperability: the consumer (Epic 3) is environment-agnostic precisely because any environment can satisfy this contract. Without the published contract, operators in pinned environments would hit the guard's missing-reading stop with no self-service path.
