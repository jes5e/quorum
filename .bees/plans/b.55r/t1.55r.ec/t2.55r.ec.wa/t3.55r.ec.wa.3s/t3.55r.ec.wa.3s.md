## Context

- The `## Tech stack` helper-scripts bullet (currently near docs/sdd.md:6; line numbers advisory — re-resolve by heading at execute time) — it currently reads "Two exist today" and names only `detect_fast_path.py` and `scoped_marker_resolver.py`. **That count is already stale by one**: `skills/quo-execute/scripts/hive_commit.py` exists on disk but is absent from the list. - The `## Key components` list — one bullet per existing helper (currently near docs/sdd.md:55-57). `context_gauge.py` needs a bullet. (`hive_commit.py`'s own bullet was a pre-existing gap fixed directly during the breakdown run's deferral gate — it already exists by the time this Subtask runs; do not edit it.)

It is repo-authoritative prose agents read at run time, and no sibling lane owns it — fixing the SDD alone would leave two authoritative docs disagreeing about how many bundled helpers exist.

This staleness has no other owner. Epic 3 (t1.55r.h9) owns the cumulative `### Feature: Context-window guard for long orchestrator runs` subsection under `## Per-feature design` — a different part of the document that does not touch these structural catalogs.
