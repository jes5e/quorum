## What Needs to Change

Create the new file `skills/quo-setup/scripts/context_gauge.py`, stdlib-only Python 3, matching the conventions of the three existing bundled helpers:

1. `#!/usr/bin/env python3` shebang plus a module docstring in the style of `skills/quo-execute/scripts/hive_commit.py` lines 1-101: state what the helper is for, then a `CLI contract` block documenting both subcommands (`produce [--wrap-command <cmd>]`, `read --session-id <id>`), the gauge file path, the written JSON shape `{"session_id": ..., "context_window": {...}}`, the four `read` output values, the fail-safe contract rules a consumer must honor (never treat an absent, null, or stale reading as `0` or as headroom; `stale` and `no-reading` are distinct values that must not be collapsed), and the exit-code contract (0 for every normal state; 2 only on genuine malformation). Do NOT enumerate per-value stop/continue routing or any opt-out mechanism — that consumer behavior does not exist yet (it ships with a later feature), and a shipped source file must not describe unshipped behavior. Include an `Invariants (load-bearing)` block mirroring hive_commit.py lines 90-100 that states: never write outside the gauge directory; never delete any file; overwrite-per-refresh (truncate-and-write, never append); the path and field names are a protected cross-skill contract shared with the quo-setup installer, the execution-skill consumers, and any environment-owner producer. **This Subtask has sole ownership of the docstring's CLI-contract block** — the sibling `produce`/`read` Subtasks add function-level docstrings only and do not edit the module docstring (they run in parallel against this file; a shared edit region would make them conflict).

2. Imports (stdlib only) — exactly what the skeleton itself uses: `argparse`, `re`, `sys`, `tempfile`, and `from pathlib import Path`. Do not import anything the skeleton does not use — pyflakes must be clean at this Subtask's boundary. The sibling Subtasks add their own imports when they first use them (the `produce` Subtask adds `json`, `os`, `subprocess`; the `read` Subtask adds `json`, `time`, and any `typing` import it needs).

3. Module-level named constants, each defined exactly once, each with a short comment stating its rationale in project-neutral terms (no spec-document identifiers, ticket IDs, or plan-review history in the shipped file — it installs into other projects where those references dangle):
   - `STOP_THRESHOLD_PERCENT = 50` — comment records the arithmetic: harness auto-compaction fires near ~83% of the window; a single large unit of work can consume ~25-30% — a figure the comment must label as **an unverified working estimate, not a measured or enforced budget** (nothing in the workflow measures per-unit consumption); 50 + ~30 stays under ~83, so 50 is the highest safe stop point (raising it to 55 fails that arithmetic: 55 + 30 = 85 > 83). Note this is the single tunable definition site consumers read rather than re-derive.
   - `FRESHNESS_WINDOW_SECONDS = 120` — comment states that freshness is judged from the gauge file's modification time (no embedded timestamp field) and that overwrite-per-refresh is what keeps mtime current.
   - `GAUGE_DIR_NAME = ".quorum"` and a single filename template constant (e.g. `GAUGE_FILENAME_TEMPLATE = "context-usage-{session_id}.json"`) so the contract string exists in exactly one place in executable code.
   - `SESSION_ID_RE = re.compile(r"^[A-Za-z0-9._-]+$")` — a conservative charset guard so a session id can never contain a path separator or `..` and escape the `.quorum` namespace.

4. `def fail(message: str) -> int:` — print one human-readable line to stderr, `return 2`. Byte-for-byte the convention at `skills/quo-execute/scripts/hive_commit.py:114-116` and `skills/quo-breakdown-epic/scripts/scoped_marker_resolver.py:96-98`.

5. Path-derivation functions (the single definition site of the file contract; both subcommands call these):
   - `def gauge_dir() -> Path:` — `Path(tempfile.gettempdir()) / GAUGE_DIR_NAME`. Pure, creates nothing (so tests can call it after monkeypatching the tempdir).
   - `def ensure_gauge_dir() -> Path:` — `gauge_dir()` with `mkdir(parents=True, exist_ok=True)`, returning the Path. Create-if-absent per the scratch-file convention. Never deletes.
   - `def is_valid_session_id(session_id) -> bool:` — non-empty `str` matching `SESSION_ID_RE`.
   - `def gauge_path(session_id: str) -> Path:` — `gauge_dir() / GAUGE_FILENAME_TEMPLATE.format(session_id=session_id)`. Docstring must state the caller is responsible for validating the id first.

6. `def main() -> int:` with an `argparse.ArgumentParser` and `add_subparsers(dest="mode", required=True)` declaring both subcommands, modeled on `hive_commit.py:247-304`:
   - `produce` with `--wrap-command` (optional, single string).
   - `read` with `--session-id` (required).
   Normalize argparse usage errors to exit 2 with the same `try: args = parser.parse_args() / except SystemExit as e: return e.code if isinstance(e.code, int) else 2` shape used at hive_commit.py:292-295. Dispatch to `cmd_produce(args)` / `cmd_read(args)`.

7. Placeholder `def cmd_produce(args) -> int:` and `def cmd_read(args) -> int:` bodies that `return 0` with a one-line `# implemented in <sibling subtask>` comment, so the skeleton runs and lints clean; the sibling Subtasks replace them.

8. `if __name__ == "__main__": sys.exit(main())` (hive_commit.py:307-308).

Do NOT add a `--threshold` flag, an opt-out-marker path, or any consumer-side branching logic — the opt-out marker (SR-2.8) and the boundary branch table (SR-2.3) belong to Epic 3.

- `ensure_gauge_dir()` creates the directory when absent and is idempotent when present; nothing in the file calls `os.remove`, `Path.unlink`, `shutil.rmtree`, or any other delete API (grep confirms zero occurrences).
- The file is a single stdlib-only Python file with the `#!/usr/bin/env python3` shebang and the `sys.exit(main())` entry; `python -m pyflakes skills/*/scripts/*.py` (repo CLAUDE.md **Lint**) reports nothing for it — in particular, no unused imports at this Subtask's boundary.
- The module docstring and comments contain no spec-document section identifiers, ticket IDs, or plan-review history (project-neutral prose).
- The `STOP_THRESHOLD_PERCENT` rationale comment labels the ~25-30% per-unit figure as an unverified working estimate; the figure is never *characterized* as a budget — the negated mention ("not a measured or enforced budget") is the required form, so this is NOT a bare-word grep ban on "budget".
