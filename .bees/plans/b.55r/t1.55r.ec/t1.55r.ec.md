## Context

Foundational Epic for the context-window guard. Produces the single bundled helper that both writes the per-session context-usage gauge (producer) and classifies a reading for the boundary check (consumer read path), plus the published file contract that Epics 2 and 3 depend on. Nothing else in the workflow reads or writes context usage today, so this Epic is greenfield and stands alone.

Authoritative spec: Spec Bee **b.8sh** → SDD `## Requirements` SR-1 (producer), SR-2.1/SR-2.2 (threshold constant + read subcommand), `## Test Fixtures`, and the `## Codebase exploration findings` helper/test conventions.

## What Needs to Change

- Add a bundled cross-platform Python helper (proposed `skills/quo-setup/scripts/context_gauge.py`, stdlib-only, matching the `detect_fast_path.py` / `scoped_marker_resolver.py` / `hive_commit.py` conventions: argparse subcommands, `fail()`→exit-2, `sys.exit(main())`) exposing:
  - `produce [--wrap-command <cmd>]` — read the status-line JSON from stdin once, write `{session_id, context_window}` to `<tempdir>/.quorum/context-usage-<session_id>.json` (overwrite-per-refresh, session-keyed, create `.quorum` if absent, never delete); no-op exit 0 when `session_id` absent; with `--wrap-command`, re-emit the wrapped command's stdout as display after writing (wrap-don't-replace); without it, print a minimal default display from `workspace.current_dir`/`cwd`.
  - `read --session-id <id>` — print exactly one of FOUR values: the integer `used_percentage`; `no-reading` (file present, fresh, percentage null/absent); `stale` (file present but its mtime is older than a freshness-window named constant, default ~120s — a stalled producer); or `missing` (file absent). Exit 0 for all four; exit 2 only on a genuinely malformed file. Two named constants: the **threshold, default 50%** (see SDD SR-2.1; do not implement 55%, superseded in plan review) and the **freshness window, default ~120s** (see SDD SR-1.6/SR-2.2). `stale` is distinct from `no-reading` on purpose (SDD SR-2.2): the consumer routes `stale`→stop but `no-reading`→continue, so collapsing them would drop the round-2 stalled-producer fix.
- Add `tests/test_context_gauge.py` following the two-layer conftest pattern (unit via `load_script`, CLI-contract via `script_path` + `subprocess.run`, `tmp_path` + `monkeypatch` for temp-dir/env/stdin), and add a `CONTEXT_GAUGE` relpath constant to `tests/conftest.py`. Cover: overwrite semantics, session-keyed parallel isolation, missing-session no-op, `--wrap-command` passthrough, all four `read` classifications (integer / `no-reading` / `stale` via an `os.utime`-aged gauge file / `missing`), malformed-file exit 2.
- Publish the gauge-file contract in the customer-facing docs (`Customer-facing docs` key): the path, the required fields, the overwrite-per-session semantics, and the restricted/pinned-statusline-environment note telling an environment owner how to satisfy it with their own producer. The contract is *defined* by this Epic, so its documentation folds in here rather than a separate doc Epic.

## Cross-Task / cross-Epic contract

This Epic **defines the gauge-file contract** — the path `<tempdir>/.quorum/context-usage-<session_id>.json` and the field names (`session_id`, `context_window.used_percentage`, and the rest of the `context_window` object). Epic 2 (quo-setup install) points the status line at this helper's `produce`; Epic 3 (boundary guard) calls this helper's `read`. Treat the path and field names as a protected cross-skill contract per the SDD `## Existing Behavior` note — do not rename without updating all consumers and the README in lockstep.

## Acceptance Criteria

- `context_gauge.py produce` writes the gauge file with the specified shape and overwrite/session-keyed/no-delete semantics; `--wrap-command` re-emits the wrapped display while still writing the gauge; missing `session_id` is a 0-exit no-op. *(Demo: pipe a sample status-line JSON in; inspect the written file; run twice with two session ids and see two distinct files.)*
- `context_gauge.py read --session-id <id>` returns integer / `no-reading` / `stale` / `missing` correctly and never implies 0 for absent/null/stale; malformed file exits 2. *(Demo: read against a present-numeric, present-null, mtime-aged (stale), and absent file.)*
- `tests/test_context_gauge.py` passes under the project **Full test** command; `conftest.py` gains the `CONTEXT_GAUGE` constant; **Lint** (pyflakes) is clean.
- The customer-facing docs publish the file-contract section (path, fields, overwrite-per-session semantics) plus the restricted-environments note.
- All new shell/doc snippets are paired POSIX + PowerShell; the helper is a single Python file; no `rm`/cleanup of scratch files; prose stays project-neutral.
