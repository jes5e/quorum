## Context

Task 2 of Epic 3 adds an additive threshold-emitting seam to `skills/quo-setup/scripts/context_gauge.py`: a new orthogonal subcommand `stop-threshold` that prints the integer `STOP_THRESHOLD_PERCENT` (currently 50) so a consumer can obtain the stop threshold from the helper via one invocation, rather than re-deriving it. Scope the assertions to the contract — "one invocation yields the threshold integer on stdout, exit 0" — reading the exact subcommand name from the landed helper / its `--help`. Add this as a CLI-contract test (Layer 2) alongside the existing subprocess tests, matching the established `_run(...)` + json/stdout style. Follow the Test writing guide (CLAUDE.md `## Documentation Locations`) and the fixtures in `docs/sdd.md` `## Test Fixtures`. Unit/CLI-contract test work only.

## What Needs to Change

All edits are in `tests/test_context_gauge.py`, added near the CLI-contract argparse section (around `test_cli_help_*`).

1. **CLI-contract emit test.** Invoke the helper's threshold seam via the exact subcommand the Engineer landed (`stop-threshold`; confirm from the helper / its `--help`). Assert `res.returncode == 0`, and that stdout parses to an integer equal to `mod.STOP_THRESHOLD_PERCENT` (reference the constant symbolically rather than hardcoding 50, so the test is a genuine single-definition-site pin). Use the established temp-dir env helper, consistent with the other CLI tests. Assert stderr is empty on the success path.

2. **Threshold value is the tunable, unchanged.** Assert the emitted integer equals `mod.STOP_THRESHOLD_PERCENT` AND (in `test_tunable_constants` where it already lives) that `mod.STOP_THRESHOLD_PERCENT == 50`. Keep the emit assertion tied to the constant so a future retune of the tunable and the seam stay in agreement.

3. **Argparse surface.** Since the seam is a subcommand, add a light assertion that `--help` lists it (mirroring `test_cli_help_names_the_inspection_subcommand`) and that an unknown flag to it exits 2 (mirroring `test_cli_inspect_statusline_unknown_flag_exits_2`).

4. **Do not over-specify output shape.** The Task pins only that the consumer can obtain the threshold integer from one invocation. Parse `res.stdout.strip()` to an int and compare to the constant rather than asserting a byte-exact string, unless the landed helper clearly commits to an exact trailing-newline shape.
