## Outcome

The gauge helper derives the stop threshold at run time from the operator's effective compaction window and the next unit's size — mirroring the harness's own resolver — with no change to what today's orchestrators call, so the installed skills keep working and immediately get a correct threshold. Demonstrable by running `stop-threshold` with different `--units` values and compaction-window settings.

## Decision carried in from Issue b.y2q (2026-09-03)

`read` classifies a gauge **directory** that cannot be traversed (owned by another user with a non-traversable mode) or that is not a directory as `missing`, not as a malformed-gauge exit `2`, and prints one stderr diagnostic naming the directory and the likely cause (ownership/mode). Rationale: under this plan's fail-open design, `missing` yields a one-line notice that (per Epic 2) names an unwritable gauge directory as a cause and continues, whereas exit `2` would hard-stop at every boundary for a condition the operator cannot fix mid-run. The four-value `read` vocabulary and the exit-`2` contract for a malformed gauge *file* are unchanged; only the directory-level case moves. Update the docstring's Exit codes / Invariants / Decision record (which b.y2q widened to document the old directory behavior honestly) and add tests for the non-traversable and not-a-directory cases mapping to `missing`. This supersedes the "open policy question" the b.y2q run recorded in Issue b.ebw's deferral.
